# TRYX – Personal Portfolio Website

## About the Project

TRYX is my personal portfolio website developed to showcase my background, educational experience, technical skills, projects, and certifications as a Bachelor of Science in Information Technology student.

## Features

- Personal introduction and about section
- Educational background
- Technical skills
- Featured projects
- Certificates and achievements
- Resume section
- Contact information
- Light and dark mode
- Responsive website design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Development Tools

- Visual Studio Code
- GitHub
- Vercel

## How to Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server or your preferred browser.
